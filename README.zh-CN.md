Glance 是一个免费开源、不打扰你的 Windows 系统监控。把鼠标推到屏幕边缘，面板滑出，电脑此刻的状态一目了然；移开鼠标，面板收回。0.4 起又多了两个组件：放随手要用的东西的[工作台](#工作台)，和跟着歌词走的[音乐](#音乐)。每个组件都可以放在任意一条屏幕边缘，也可以拖到桌面上。

## 显示什么

- **CPU**：占用、每个线程（鼠标指上去显示它的频率）、频率（大小核处理器分别显示大核和小核的频率）、温度、封装功耗、每个 CCD 的温度
- **GPU**：占用、显存、频率、温度、风扇，以及 NVIDIA 和 AMD 独立显卡的功耗；Intel Arc 显卡的温度、频率、风扇和功耗来自 Intel 自己的驱动库；驱动单独提供热点温度的显卡（RTX 50 系之前的 NVIDIA 显卡、AMD 独立显卡）会多一行热点温度
- **内存**：用量、运行频率（低于内存条额定频率时一并显示），以及每根内存条的温度
- **网络和磁盘**：流量，可选显示连接的 Wi-Fi 名称，以及每块硬盘的温度，多块硬盘各占一行
- **进程**：按 CPU、内存、读写或 GPU 排序的最忙程序
- **存储**：每个分区的空间
- **主板**：各处温度和风扇转速
- **电池**：笔记本上显示电量、充放电功率（拔掉电源时就是整机耗电）和电池健康度
- **时间与媒体**（默认关闭）：时间和日期（可选 12 小时制）、可以拖动的音量条和静音，以及正在播放的内容，可以暂停、播放和切换曲目
- **WSL 和 Docker**，给开发者用（默认关闭，在“更多模块”里打开）：WSL 2 的处理器、内存、GPU 占用和正在运行的发行版，只从 Windows 一侧读取，不会启动发行版，也不会让它停不下来；Docker 当前引擎运行中的每个容器占用的处理器、内存、网络和磁盘
- **游戏**：全屏游戏运行时自动出现在最上面：帧率、1% low、帧时间图、屏幕刷新率，游戏自己占用的 CPU、GPU、内存和显存，显卡是否撞上功耗墙或温度墙（NVIDIA），这次玩了多久，以及麦克风是否静音

## 工作台

第二个面板，放随手要用的东西，可以放在任意一条边上（比如左边放工作台、右边放监控）。大小可以随意调整，各个模块按空间自动排布。

- **中转站**：把文件、图片、文字和链接拖进来或粘贴进来，它们会一直放在这里，直到你把它们拖进别的程序。“最近复制”保存经过剪贴板的内容（可以暂停），“最近文件”列出刚下载或保存的文件。双击打开，右键固定，可以按卡片或列表显示，放得太久的会自动清理。
- **便签**，用 Markdown 书写：每条便签是“文档\Glance 便签”（也可以另选文件夹）里的一个 `.md` 文件，任何编辑器都能打开。标题、强调、待办方框和链接按排版后的样子显示，点一下就能勾选方框或打开链接，Markdown 标记只在正在编辑的那一行显示。便签可以贴到桌面上，直接在桌面上编辑。其他程序对便签的修改会被读入，任何内容都不会在未读取的情况下被覆盖。
- **快捷启动**：常用的程序、文件、文件夹和网址并排放着，点一下就能打开。可以从全部开始菜单程序、最近使用的项目中添加，也可以直接拖进来。
- **时间与媒体**：时间、日期和正在播放的内容。

## 音乐

显示正在播放的歌，包括封面、播放控制、进度、音量和跟着歌声走的歌词，有逐字时间的歌会一个字一个字亮起来。改变大小时形态随之变化：一行歌词的横条、播放器、显示前后几句的卡片，足够宽时变成带转动唱片和频谱的舞台。全屏时歌词以大字显示，背后的烟雾取封面的颜色，跟着节拍流动。打开“透明背景”，它就是一行浮在桌面上的歌词。封面、歌名、翻译、频谱和播放控件都可以单独关闭。

歌词从网易云音乐、QQ 音乐、酷狗、LRCLIB 和 Apple Music（经其服务 PaxSenix，免登录）同时查找，本地歌曲优先使用文件自带的歌词，有翻译时显示翻译。能在 Windows 媒体浮窗里显示歌名的播放器都可以使用。网易云音乐需要 InfLink-rs 插件才能提供播放进度，设置里可以一键安装。

## 桌面小组件

把面板（监控、工作台或音乐）从屏幕边缘拖开，它就会被“撕”下来，变成留在桌面上的小组件：按住某个模块的标题拖，只撕下这一个模块，按住其他地方拖则撕下整个面板。拖任意一条边或一个角调整大小，内容会按空间自动排版：监控原来的各栏、方块、上面是曲线下面是读数的卡片、横条，或者几个小圆环，形态之间平滑过渡。拖到屏幕边缘附近，会提示它将贴靠的位置，松手后它按原来的大小贴在这条边上，拖动时沿着边滑动。把它甩出屏幕就会收起，托盘菜单可以召回。鼠标移上去会出现一排按钮，停在按钮上会显示它的用途：显示当前窗口的帧率（Glance 没认出来的游戏也可以）、设置、固定位置和大小的图钉、鼠标穿透，以及收起。开启鼠标穿透后，点击会落到后面的窗口上；要关闭它，把鼠标在小组件上停留片刻，点出现的那个按钮。右键菜单里也有这些，还可以取消"置于其他窗口之上"，它就留在桌面上，被其他窗口盖住，按 Win+D 显示桌面时和桌面一起出现；也可以收起，或打开设置。Glance 重启后小组件会回到原来的位置，外观与面板一致。

![磨砂玻璃外观的小组件：面板各栏、方块、曲线卡片、横条和小圆环](docs/images/widgets-zh.webp)

## 悬浮窗

几项读数浮在屏幕上，可以一直显示，也可以只在玩游戏时出现。布局有两种：卡片（帧率放大显示，旁边是最近一分钟的帧率曲线，其余读数排成小格）和横条（一到三行）。读数放在一块半透明的玻璃上：玻璃按周围画面的明暗自动选深色或浅色，着色只加到每个数字都看得清为止（不模糊背后的画面，模糊会占用游戏的帧率）。拖动它调整位置，拖边角调整大小。鼠标移上去会出现和小组件相同的一排按钮：显示当前窗口的帧率、设置、锁定位置、鼠标穿透和关闭，右键菜单里也有。在它上面滚动鼠标滚轮（或用设置里的滑块）可以把玻璃调得更透明，直到只剩读数浮在画面上。开启鼠标穿透后，点击会落到后面的游戏上；要关闭它，把鼠标在悬浮窗上停留片刻，点出现的那个按钮。显示项目和面板一样按组设置：帧率、CPU、GPU、内存、显存、下载和上传、麦克风、时间，每组里的项目可以单独开关，拖动可以调整顺序。

![悬浮窗的卡片布局：帧率放大显示，旁边是帧率曲线，CPU 和 GPU 排成小格](docs/images/overlay-card-zh.webp)

![悬浮窗的横条布局，一行](docs/images/overlay-strip-zh.webp)

帧率来自 Windows 自带的事件跟踪：不往游戏里注入任何东西，也从不打开游戏进程，不会触碰反作弊。目前支持 DirectX 游戏，Vulkan 和 OpenGL 游戏暂不显示帧率。

## 手机遥控

躺下之后不想再起来，电脑还要继续下载：手机上装一个小 APP，就能给电脑关屏幕、关机箱灯、调音量和每台显示器的亮度、暂停或切歌、切换电源模式、让电脑睡眠，顺便看一眼温度。“夜间模式”一键关屏、关灯、切到节能，动一下鼠标就恢复。

- **开启**：在设置的“手机遥控”里打开。默认关闭；Glance 本身从不开放端口，遥控由另一个小程序（`glance-remote.exe`）负责，它以你的身份运行、从不提权，防火墙只对本地网络放行。
- **下载 APP**：[glancepc.com/app](https://glancepc.com/app)（安卓 8.0 及以上，APK 随每个版本发布）。iPhone 的 APP 还在做，暂时可以用遥控程序自带的网页。
- **配对**：用手机扫描设置里的二维码。每部手机有自己的密钥，只对这一部手机有效，随时可以在设置里移除。每个请求都用它签名，不经过任何服务器，出了你家的网络就用不了。
- **也可以在电脑上用**：设置的“手机遥控”页右侧就是 APP 的画面，可以直接点按和拖动。保存的灯光颜色存在电脑上，手机和电脑看到的是同一份。
- **灯光**：主板和显卡的灯由开源软件 [OpenRGB](https://openrgb.org)（GPL 许可）控制，只有在你打开“控制灯光”时才会从它的官方地址下载（约 22 MB），关闭时一并删除。利民散热器的数显屏会跟着一起开关。
- **笔记本**：APP 里画的是笔记本，“灯光”就是键盘背光（目前支持华硕笔记本）：能调档位，键盘支持变色的还能选颜色和效果，不需要 OpenRGB。关屏时电脑不会进入待机，动一下就亮，不用重新登录。
- 网页走的是不加密的 HTTP，请只在信任的网络里使用。APP 的请求别人无法伪造或重放，但电脑返回的内容（温度、正在播放的歌曲）在同一网络里并不保密。

## 小巧安静

程序只有一个约 2 MB 的可执行文件，用 Direct2D 和 DirectComposition 原生绘制。面板收起时约占 55 MB 内存，CPU 占用远低于一个核心的 1%。不需要账号，没有广告；除每天查询一次新版本（向 Glance 自己的网站以及 GitHub、Gitee）外不联网（这项检查可以在设置中关闭）；另外只有两种情况会用到网络：你在设置里主动发送诊断信息（发送前会完整显示内容，可以附一句话和截图），以及你自己开启的手机遥控。

## 安装

1. 从[最新版本](https://github.com/lulu-loopp/glance/releases/latest)下载 `Glance_<版本>_x64-setup.exe` 并运行。GitHub 打不开时，可以从 [Gitee 镜像](https://gitee.com/lulu-loopp/glance/releases)下载同一个安装程序。
2. 安装程序已签名（发布者：Weiyi Shi）。由于签名刚开始使用，最初的一段时间里 Windows SmartScreen 仍可能提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”即可。
3. Glance 第一次启动时会请求一次管理员权限：读取温度、功耗和风扇需要它，通过安装程序装好的已签名驱动 [PawnIO](https://github.com/namazso/PawnIO) 完成。此后启动不再询问，也可以设置为开机时启动。

**安装位置。** 只有安装在普通程序无法修改的文件夹里，Glance 才会不经询问地以管理员身份启动：默认的 Program Files，或磁盘根目录下的新文件夹（例如 `D:\Glance`）。选择其他位置时，安装程序会说明影响；装在那里的 Glance 每次启动都需要确认管理员权限，也无法开机时启动。

## 使用

- **打开面板**：把鼠标推向屏幕右边缘（需要多大力度、面板出现在什么位置、分几栏、面板大小，都可以在设置中调整）。设置的“布局”页按 Windows 的排列画出各块屏幕：把监控、工作台或音乐拖到任意一条边上即可，一条边可以放多个组件，没有放组件的边不会弹出面板。需要有意识地推一下才会打开，所以屏幕边缘的滚动条照常可用。有多块屏幕时，设置里会按实际排布画出每一块：点任意一块屏幕的左、上、右边，面板就能从那里呼出，再点一次取消。连着另一块屏幕的边，改为把鼠标贴着它停半秒呼出。也可以按 **Ctrl+Alt+G**（快捷键可以自定义），在鼠标所在位置打开面板，再按一次收起。
- **玩游戏时**：全屏游戏运行时，面板最上面会自动出现"游戏"一栏；想在游戏画面上看帧率，就在设置的"悬浮窗"页打开"游戏时自动显示"。全屏和无边框全屏的游戏里，设置可以选择怎样呼出面板（默认仅快捷键，免得游戏中鼠标碰到边缘误触）。显示模式设为"全屏"的游戏，只要有东西盖上去就会暂时切出，这是 Windows 的机制，面板收起后游戏会自动回来；窗口模式的游戏里，面板照常叠在游戏上。
- **选择显示内容**：在设置里，每个模块（CPU、每张显卡、内存、网络、硬盘……）都能展开，里面每一项单独开关；拖动模块可以调整顺序。WSL 和 Docker 收在“更多模块”里，打开后才出现。
- **收起面板**：把鼠标移开，或按 Esc。
- **调整大小**：面板打开后就可以拖它的边角调整大小。
- **留在桌面上**：把面板从屏幕边缘拖开，它会变成小组件留在桌面上（见[桌面小组件](#桌面小组件)），也可以拖到另一块屏幕。
- **固定面板**：点面板底栏的图钉，面板会一直显示，方便边做别的事边看；Glance 重启后也会自动打开并保持固定。
- **随时一瞥**：鼠标悬停在托盘图标上，会显示 CPU、显卡和内存的简要读数。开启“过热提醒”（默认关闭）后，CPU 或显卡持续 30 秒达到温度警示值时，托盘会弹出提醒。
- **设置**：右键单击托盘图标，或再次启动 Glance。设置窗口也可以用键盘操作（Tab、方向键、空格）。
- **更新**：Glance 每天向自己的网站（glancepc.com）以及 GitHub、Gitee 镜像查询一次新版本，哪边连得上就用哪边。向自己的网站查询时，Glance 会告知当前版本、是否为新安装后的第一次查询、从哪个版本更新而来，以及已在这台电脑上使用了几周；网站据此统计有多少份 Glance 在运行、是否及时更新。其中没有任何能区分具体某台电脑的信息：不发送名称或编号，网站也不保存地址。有新版本时，托盘会提示，设置中会出现更新按钮。Glance 下载安装程序后，只有确认其签名与当前 Glance 出自同一发布者，才会运行它。
- **卸载**：在“设置 → 应用 → 已安装的应用”中卸载，或在 Glance 的设置中卸载。卸载会删除 Glance、它的计划任务和设置，并询问是否一并卸载 PawnIO 驱动（其他监控软件可能也在使用它）。

## 硬件支持

| | 支持 | 已在真机上验证 |
|---|---|---|
| CPU | AMD Ryzen（Zen 及以后）、Intel Core | AMD Ryzen 9 9950X |
| 主板传感器 | ITE 和 Nuvoton（NCT67xx，以及微星常用的 NCT6683/6686/6687）Super I/O 芯片 | ITE IT8689E |
| 内存温度 | 带传感器的 DDR4 和 DDR5 内存条 | DDR5 |
| 显卡功耗 | NVIDIA（NVML）、AMD（ADL）独立显卡 | NVIDIA RTX 5070 Ti |
| 其他读数 | 通过 Windows 获取（与任务管理器相同的数据来源） | |

欢迎 Intel 和 Nuvoton 机器的用户反馈实际效果：在“设置 → 系统 → 诊断信息”中点“复制”，Glance 会把识别到的硬件、读数情况和最近的日志复制到剪贴板，直接粘贴到 issue 即可（不包含路径或用户名）。日志文件是设置旁边的 `%APPDATA%\dev.weiyi.glance\glance.log`。笔记本的风扇和主板温度由笔记本自己的嵌入式控制器管理，Glance 暂不显示（华硕笔记本的风扇除外，由固件提供）；核显的功耗包含在 CPU 封装功耗里，在 CPU 一栏中显示。

## 构建

```
cargo build --release
makensis installer\glance.nsi
```

`scripts\release.ps1` 会完成以上两步，并构建手机遥控程序（`remote\`，独立的 crate）。加上 `-Sign` 时，还会为可执行文件、卸载程序和安装程序签名（使用 Microsoft Artifact Signing，通过发布者自己的 `scripts\sign.ps1`，该脚本不在仓库中）。安卓 APP 在 `android\` 目录（`gradlew assembleRelease`，需要 JDK 17）。调试版本启动时不请求管理员权限，因此也没有驱动提供的传感器读数。

本页的图片和宣传视频都由 Glance 自己绘制：`cargo build --release --features studio` 会加入 `glance --studio script.json out-folder` 命令，按镜头脚本在屏幕外逐帧渲染面板。
