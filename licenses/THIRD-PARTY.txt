Third-party software in Glance
==============================

Glance ships with, or has built into it, the following. Their licences are
in this folder; where a licence asks for the source code, it says where the
source is.


PawnIO driver setup (resources\PawnIO_setup.exe), version 2.2.0
  PawnIO - Input-output driver. Copyright (C) namazso <admin@namazso.eu>.
  Licence: GNU General Public License, version 2, with an exception for
  independent programs that talk to PawnIO only through its device I/O
  control interface, as Glance does. The notice, with the exception in
  full, is PawnIO-NOTICE.txt; the licence, PawnIO-GPL-2.0.txt.
  Glance redistributes the setup unmodified. Its source code, for this
  version: https://github.com/namazso/PawnIO/tree/2.2.0
  The same source, with the submodule it builds with, is attached as an
  archive to every Glance release that includes the setup.

PawnIO modules (AMDFamily17, IntelMSR, LpcIO, SmbusPIIX4, SmbusI801),
  release 0.2.11
  Copyright (C) namazso and the PawnIO.Modules contributors.
  Licence: GNU Lesser General Public License, version 2.1
  (PawnIO-Modules-LGPL-2.1.txt).
  Built into glance.exe as compiled modules, loaded into the PawnIO driver
  at run time, unmodified. Their source code, and how they are compiled, is
  in the folder pawnio-modules-source next to this file (BUILD.md), and at
  https://github.com/namazso/PawnIO.Modules/tree/0.2.11
  Glance's own source, to rebuild it with changed modules, is at
  https://github.com/lulu-loopp/glance

Archivo (fonts, Latin subset)

Lucide (icons: cpu, gpu, memory-stick, hard-drive, arrow-down-up,
  gamepad-2, pin, x, settings, check, mouse-pointer-2, panel-right, undo-2,
  refresh-cw, power),
  from lucide-static 1.53.0
  Copyright (c) Lucide Icons and Contributors.
  Licence: ISC (Lucide-ISC.txt); x comes from Feather,
  Copyright (c) 2013-present Cole Bemis, under the MIT licence in the same
  file. Their path data is built into glance.exe.

Glass Card (the coloured glass of the notes' cards: its swatches' tints and
  inks, and how its material frosts what lies under a card)
  Copyright (c) 2026 Chunlong Ko (https://github.com/alexko0421/glass-card).
  Licence: MIT (glass-card-MIT.txt). Its colours and the way it is drawn are
  reworked in glance.exe's own code.

Unicode Character Database (Unihan, Chinese characters' Mandarin readings, for
  searching programs and files by pinyin)
  Copyright (c) 1991-2026 Unicode, Inc.
  Licence: Unicode License v3 (Unicode-License-v3.txt). Two tables derived from
  Unihan_Readings.txt (scripts/pinyin.py, scripts/readings.py) are built into
  glance.exe.

OpenRGB, version 1.0 (not shipped with Glance)
  OpenRGB - open source RGB lighting control. Copyright (C) Adam Honse and
  the OpenRGB contributors. Licence: GNU General Public License, version 2
  or later.
  The phone remote (glance-remote.exe) sets a motherboard's and a graphics
  card's lights through OpenRGB, a separate program it starts and talks to
  over OpenRGB's own network protocol. OpenRGB is not part of Glance and is
  not installed with it: it is downloaded, unmodified, as its project built
  it (OpenRGB_1.0_Windows_64_81bbe18.zip), only when "Control the lights"
  is turned on in the settings, into the user's own folder, and removed
  when that is turned off. It is taken from a copy on Glance's site
  (https://glancepc.com/dl/OpenRGB_1.0_Windows_64_81bbe18.zip), or from the
  project itself:
  https://codeberg.org/OpenRGB/OpenRGB/releases/tag/release_1.0
  Its source code, for this version, is at
  https://codeberg.org/OpenRGB/OpenRGB/src/tag/release_1.0
  and, as an archive, beside the copy on Glance's site
  (https://glancepc.com/dl/OpenRGB-release_1.0-source.zip) and attached to
  Glance's releases.

Rust crates and the Rust standard library
  The crates compiled into glance.exe and glance-remote.exe, each with the
  licence files it ships with, are listed in RUST-CRATES.txt; the standard library's notices are in
  Rust-standard-library-COPYRIGHT.html (from the Rust 1.94.1 toolchain).
